# cityoftraitors.com (SvelteKit App)

SvelteKit 2 + Svelte 5 static site powered by `@sveltejs/adapter-static` and `mdsvex`.

## Scripts

- `npm run dev` — Start Vite development server
- `npm run check` — Run `svelte-kit sync` and `svelte-check`
- `npm run build` — Build static site into `build/`
- `npm run preview` — Preview the built static output

See the repository root [README.md](../README.md) and [STYLE_GUIDE.md](../STYLE_GUIDE.md) for authoring and design documentation.
